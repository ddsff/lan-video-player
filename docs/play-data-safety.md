# Google Play 数据安全填报草稿

适用版本为「局域网播放器」0.7.3（`com.lanvideo.player`）。以最终提交的构建和 Play Console 的实际问项为准。

| 功能 | 数据流与填报依据 |
| --- | --- |
| 局域网发现 | 用户点击扫描后，应用探测本地 IPv4 网络上的 SMB 服务。扫描结果用于填写主机地址。 |
| Windows 登录与播放 | 手机和用户指定的 SMB 服务器直接通信。账号标识和认证消息用于应用功能，按用户操作发出。共享名和路径用于列目录或读取文件，视频从共享流入播放器，缓冲在内存中。 |
| 连接历史 | 本机加密保存电脑地址、共享名、Windows 用户名，密码由用户选择是否保存。可以删除单条记录的密码或清除全部历史。备份规则排除此历史。 |
| 播放设置 | 本机保存播放选项。 |
| 诊断 | 应用内诊断保存在进程内存，发布版系统日志隐藏地址和共享名。用户可以把应用内日志复制到剪贴板。应用不上传日志。 |
| 开发者服务 | 没有开发者账号、广告、分析、崩溃上报或遥测后端。 |

## 在 Play Console 核对

1. **收集和共享**。仅在手机上处理的数据通常无需申报为收集。用户主动把认证请求发给自己选择的 Windows 设备是离开手机的传输。结合表单定义核对「个人信息 / 用户 ID」与适用的用户主动发起传输或临时处理条款。用户主动传输的共享豁免需要单独核对，不能据此直接得出「无收集」。
2. **用途和选择**。SMB 认证用于应用功能。登录是访问需要认证的共享的前提，本机保存密码是可选操作。
3. **传输加密**。当前客户端要求 SMB 签名。是否有 SMB 传输加密取决于实际协商及服务器配置。发布时没有强制加密的证据就不要声明传输过程中所有用户数据均已加密。
4. **删除与账号**。应用内可删除本机连接历史或已保存密码。Windows 账号由用户在主机上管理。应用没有账号创建功能。
5. **隐私政策网址与联系渠道**。将 [HTML 原文](../app/src/main/assets/privacy-policy.html) 发布为公开、可直接访问的 HTTPS 页面，配置实际可用的开发者联系渠道，并在 Play Console 填入网址。上架页面可同时说明审核测试所需的局域网环境。
